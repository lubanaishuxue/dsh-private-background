# 界面背景

给 DSH 换底图。图片、动图、视频、渐变、纯色五种来源，模糊、压暗、**取景位置**、面板浓度都能调，**对话区和输入框各自独立一档**，字体颜色可以按背景明暗自动反色。

版本 1.2.2 · Windows · DSH 桌面版

设置全在 **设置 → 插件 → 已安装插件 → 界面背景**。改完即时生效、自动保存，没有「应用」按钮，也不用重启 DSH。

图片、动图和视频只存在这台电脑上，不上传，也不会进入会话记录。

---

## 一分钟上手

1. 打开设置页，**背景类型**选「图片」
2. 点「添加图片」，选一张 —— JPG、PNG、GIF、WebP、MP4 都行
3. 拖**压暗**和**面板不透明度**，直到字看得清
4. 人没在画面中间，就在预览图上**拖着挪**
5. 想让壁纸铺满整个窗口（含左侧对话栏），打开「同时应用到左侧对话栏」

就这五步。下面全是细节，可以按需查。

---

## 设置页长什么样

从上到下六块：

| 区块 | 内容 |
|---|---|
| 背景类型 | 关闭 / 图片 / 渐变 / 纯色 |
| 来源 | 图库、6 个渐变预设、或色板 + 自选颜色 |
| 取景位置 | 在预览图上拖，或拖「左右」「上下」两条滑杆（只对图片有） |
| 作用范围 | 「同时应用到左侧对话栏」开关 |
| 字体颜色 | 跟随主题 / 自动 / 浅色 / 深色 / 自定义 |
| 观感 | 5 条滑杆 + 质感开关 |

最底下两个东西：左边「恢复默认」，右边一行诊断读数 `样式 / 激活 / 框架 / 三栏`。

## 背景类型

| 选项 | 效果 |
|---|---|
| 关闭 | 恢复 DSH 原样，什么都没变 |
| 图片 | 用图库里的图 —— 静图、动图、视频都可以 |
| 渐变 | 6 个内置预设：极光、夜幕、落日、深海、青柠、纸感 |
| 纯色 | 6 个色板，或点「自选颜色」调任意色 |

**图库**：点一张立即切换，不用确认。每张图上有「删除」；动图和视频的缩略图左下角带一个角标。

## 动图与视频

「添加」按钮选文件时可以直接选 **GIF、动态 WebP、APNG、MP4、WebM**，拖进来的动图会照常播放。

三者的处理方式不一样，因为它们的像素存在方式不一样：

| 类型 | 怎么存 | 怎么放 |
|---|---|---|
| 静图（JPG / PNG / 静态 WebP 等） | 缩到 2560px 再压成 JPEG | `background-image` |
| 动图（GIF / 动态 WebP / APNG） | **原始字节**，一个字节都不动 | `background-image` 指向原始字节 |
| 视频（MP4 / WebM） | **原始字节** | 壁纸层里放一个静音循环的 `<video>` |

动图和视频不能过 canvas：一张 GIF 画进 canvas 再读出来就只剩第一帧了。所以它们按原样存进 IndexedDB（浏览器原生支持存二进制），代价是不再受「缩到 2560px」的保护，因此单独设了 **96 MB** 的单文件上限。

视频另外会**抽第一帧做封面**。这一帧同时用在三个地方：图库缩略图、设置页预览、以及判断壁纸该配黑字还是白字。也就是说插件的亮度测量从来不读视频本体，只读这一帧。

**「减少动态效果」开着的时候，动图和视频都只显示那一帧**，不会动。

## 取景位置

图比窗口宽（或高）的时候，`cover` 会把两边裁掉。**裁掉哪边由你决定** —— 在设置页的预览图上直接拖，人物就跟着回来了。

- 也可以拖「左右」「上下」两条滑杆，或者点「居中」回到正中。
- **每张图各记各的位置**。竖构图的照片和横构图的视频本来就该裁在不同地方。
- **新传一张图从居中开始**，不继承上一张的偏移 —— 偏移是这张图的构图，不是界面风格。
- 某个方向没有多余的部分可裁（比如竖图放进横窗口的上下方向），那个方向拖不动。这不是坏了，是那个方向本来就没有可动的余地。

## 作用范围

**同时应用到左侧对话栏** —— 默认关。

- **关**：只有右边工作区换背景，左侧对话列表保持 DSH 原样。适合「我不想让壁纸干扰我找会话」。
- **开**：整窗铺满，左侧栏也变成半透明玻璃。

切到整窗后，标题栏也会跟着通栏铺满。

## 字体颜色

| 模式 | 行为 |
|---|---|
| 跟随主题 | 什么都不改，用 DSH 自己的配色（默认） |
| 自动 | 看背景实际明暗，暗背景配浅字、亮背景配深字 |
| 浅色 / 深色 | 固定，不看背景 |
| 自定义 | 你指定主色，其余几级文字由它自动推导 |

**「自动」是推荐选项**，尤其你会在亮图和暗图之间切换时 —— 它每次都会重算，不会停在上一张图的判断上。

## 五条滑杆

前四条永远在。第五条会跟着「质感」换 —— 这是唯一一个容易找不到的控件。

| 滑杆 | 范围 | 管什么 | 什么时候动它 |
|---|---|---|---|
| **模糊** | 0–40px | 壁纸本身糊多少 | 只在你不想看清图片细节时加 |
| **压暗** | 0–80% | 全场压一层黑 | **字看不清主要调这个**，不是模糊 |
| **面板不透明度** | 0–100% | 三栏的底色浓度 | 想多露壁纸就降，字发虚就升 |
| **对话区不透明度** | 0–100% | 中间聊天区单独一档 | 同上，只管对话区 |
| **输入框不透明度**（实心时） | 0–100% | 发消息那个框单独一档 | 框里的字发虚就升 |
| **玻璃模糊**（液态玻璃时） | 0–40px | 所有磨砂面板的模糊量 | 想要更「磨砂」就加 |

默认值：模糊 20 · 压暗 15 · 面板 50 · 对话区 0 · 输入框 50。

### 质感：实心 / 液态玻璃

- **实心**（默认）：各块按上面的不透明度铺底色，没有模糊、没有高光。
- **液态玻璃**：输入框、底部状态栏、头部胶囊、代码块、文件卡片、消息气泡**一起**变成磨砂半透明，边缘带一道高光。字压在图上更容易读，因为背景被磨平了。

切到液态玻璃后，第五条滑杆会从「输入框不透明度」变成「玻璃模糊」。

**设置弹窗**（侧栏齿轮或 `Ctrl+,` 打开的那一个，含「费用」「桌宠配置」等分区）走同一套材料：面板半透明 + 磨砂，里面的卡片是一层薄白纱浮在面板上。以前它是整窗唯一一块黑板 —— 因为它的底是**两层**（面板自己 + 它自带的遮罩）各压一半，加起来 73% 不透明，壁纸只剩 27%，深色图上等于没有。

面板里各分区之间也不再有分界：「费用」那页以前内容列比左边导航暗一截、而且不带一点渐变，因为计费器在弹窗已经画过的底上又铺了一块自己的板（它的 `rgb(from … / 1)` 把 alpha 写死成 1，重混到不了屏幕）。现在分区一律透明，壁纸从导航一路贯到内容区，和「桌宠配置」那页一样。

**原生下拉框**（`<select>` 展开的那一列）也跟着变暗了。它以前是一块灰底黑字、选中行浅蓝的列表 —— 那个灰不是没被覆盖，而是把「55% 的深色」当成了不透明色，压在这个列表自己的白背板上算出来的。这类列表由浏览器单独绘制、画在页面之外，读不到底下是什么，所以**只能是不透明色，也做不了壁纸和模糊**；能做的就是给它一个和菜单同色的底、把控件切进暗色。

**插件市场**（左侧栏那颗拼图图标打开的全屏页）也是透的，而且它比对话区**更实**（45% 对 22%）。这不是写错了：对话区的正文都有自己的气泡兜着，底只要负责上色；市场页的正文是 12px 小字直接坐在页面上，壁纸一亮点字就跟没了，45% 是「还看得见图、字也站得住」的那一档。卡片是薄白纱浮在这层底上 —— 它底下是已经模糊过的壁纸，再加磨砂肉眼看不出区别，只会多一层合成。

滚动时最上面那条工具栏会**真的**把底下的卡片盖住（填充 + 磨砂）。它上面原本还有一条 14px 的延伸带，宿主只给它写了 `background: inherit` —— 而 `inherit` 只继承颜色、不继承 `backdrop-filter`，所以滚过去的内容会从那一条缝里透出来。现在那条带子**直接摘掉**了：给它补一条模糊只会变成两个各自模糊、各自加填充的层，交界处照样是一道硬台阶。改成让工具栏自己的盒子往上长 8px，把滚动容器的内边距盖住，一个盒子盖到底。

工具栏本身有圆角，和下面的卡片一个半径；底下也多留了一道空隙，最后那行「已隐藏 N 个…」不再直接顶着第一排卡片。

## 每张背景各记一套参数

换一张图，滑杆会跳回那张图自己上次调好的值，不会互相污染。

| 跟着背景走 | 全局共用 |
|---|---|
| 模糊、压暗、取景位置、面板不透明度、对话区不透明度、输入框不透明度、质感 | 玻璃模糊、作用范围、字体颜色 |

分界线是**「这张图长什么样」还是「界面长什么样」**。玻璃模糊是材质 —— 一个对话框随背后的图换磨砂强度，读起来像 bug 而不像功能。字体和作用范围同理。

具体行为：

- **新传一张图，继承你当前这套** —— 传图是换画，不是换风格。**唯一例外是取景位置**：新图从居中开始，理由见上一节。
- **删掉一张图，它那套参数一起删**，不留垃圾。
- **删掉正在用的那张**，壁纸滑到顶替它位置的那一格（删的是最后一格就滑到新的最后一格）。图库空了才回到「关闭」。
- **「恢复默认」只重置当前这张背景的滑杆**，不动你选的那张图。

## 切换壁纸时的过渡

换壁纸不是硬切。新图在 0.6 秒里淡入，旧图原样留在下面，中间没有黑一下。

- 图片之间、渐变之间、色值之间，以及三者互相切换，都走同一套。
- **拖滑杆不过渡** —— 那是调参，不是换画。否则每拖一下壁纸都在自己跟自己淡化。
- **关闭壁纸仍然是立刻消失**：关掉之后就没有壁纸层了，没有东西可淡。
- 系统开了「减少动态效果」时自动关掉过渡。

**连点图库不会叠出鬼影。** 每一次点击都会把新点的那张**另起一层**叠在最上面淡入，下面那些一动不动 —— 所以没有任何一步需要「停下来等」，也没有任何一步会被打断。最后一次点击之后 0.6 秒落定，落定时上面那一层把下面全部收掉，回到一张图。

代价是连点时会同时存在好几层（手速再快也就七八层，落定时一并收掉）。层数上限 12 只是防止卡住的指针把层数堆到无上限 —— 放到这么远，是因为**丢掉一层本身也是画面上的一次变化**，只有等它被上面盖满了才看不出来。这也是为什么壁纸从「两个伪元素」换成了真实元素：`::before`/`::after` 只有两个，做不了一次连点。

## 调参顺序（省事的顺序）

大多数人第一次会直接拖模糊，然后发现字还是看不清。建议这个顺序：

1. **先选图**，别急着拖滑杆
2. **压暗**调到字能读 —— 绝大多数「看不清」是压暗不够，不是模糊不够
3. **面板不透明度**微调：想多露壁纸就降，字发虚就升
4. **模糊**最后加，只在不想看清图片细节时用
5. 想要磨砂质感再开**液态玻璃**，然后调**玻璃模糊**

原因：模糊是把壁纸磨平，代价是图没了；压暗只是把它压黑，图还在。**先压暗，后模糊。**

## 出问题了

### 设置页最底下那行读数

`样式 / 激活 / 框架 / 三栏` 后面跟四个符号，一眼能定位四类故障：

| 读数 | 显示 ✗ 意味着 |
|---|---|
| 样式 | 样式表没注入 —— 插件根本没跑起来 |
| 激活 | `<html>` 没被标记上 |
| 框架 | 没定位到 DSH 的外壳结构 |
| 三栏 | 栏数不对，宿主布局变了 |

「框架」或「三栏」有 ✗ 时页面还会多出一行错误提示。**把那一行发给我**，它比截图有用。

### 常见现象

| 现象 | 原因 / 办法 |
|---|---|
| 左边栏还是实色 | 「同时应用到左侧对话栏」没开。这是默认行为，不是 bug |
| 标题栏是一条侧栏色的实心横带 | 同上。只改工作区时，标题栏不属于工作区 |
| 右上角三个按钮是实色块 | 整窗模式下按钮颜色取自整张壁纸的平均明暗；角落特别亮或特别暗时对比度会不理想 |
| 设置页背景是纯黑 | 不是 bug —— 这一页故意不铺底，因为它是你唯一想看看壁纸效果的地方 |
| 右侧面板打开才变玻璃 | 故意的，收起时不画 |
| 图传上去变糊了 | 大图会被压到 2560px 宽再存，省内存 |
| 换图后滑杆全变了 | 不是 bug，每张图各有一套参数，见上面那节 |

## 已知边界

- 作用范围靠 DSH 的外壳结构定位，宿主大改布局会失效。失效时设置页会提示，其他界面不受影响。
- 只改工作区时，标题栏整条是侧栏色 —— 想让壁纸顶到窗口最上沿就切成整窗。
- **动态 WebP 靠 MIME 类型判断，判断不了「这张 WebP 到底动不动」** —— 所以 WebP 一律按动图处理，原样存字节。静态 WebP 因此不享受缩图，会比你预期的大一些。
- **视频壁纸会一直解码**，比静图费电。笔记本上建议插电时再用。
- 只在 Windows + DSH 桌面版上测试过。其他平台未验证。
- 插件停用后所有改动自动撤回，DSH 恢复原样，设置留在本机。
